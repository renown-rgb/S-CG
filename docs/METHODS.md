# 改进遗传算法求解稀疏单纯形LP — 方法详解

## 0. 问题公式

$$\min_{x \in \mathbb{R}^n} \; c^T x \quad \text{s.t.} \quad A x \le b,\quad \sum_{i=1}^n x_i = 1,\quad x_i \ge 0,\quad x \text{ 稀疏}$$

- **n**: 变量个数 (100 ~ 1,000,000)
- **m**: 线性约束个数 (固定 10)
- **稀疏性来源**: LP基本定理——最优解位于可行域顶点，顶点至多 $m+1=11$ 个非零分量

---

## 1. 0-1 重构：从连续到组合

### 1.1 核心定理

连续LP的最优基本可行解至多有 $m+1$ 个正分量。因此等价于：

$$\min_{z \in \{0,1\}^n} \; g(z), \quad g(z) = \min_{x}\{c^T x : Ax \le b, \sum x_i=1, x_i \ge 0, x_i=0 \; \text{if} \; z_i=0\}$$

- **外层**：GA 在 $\{0,1\}^n$ 中搜索最优支撑集
- **内层**：在支撑集上求解约化LP（仅 10-15 个变量）

### 1.2 LP Oracle（精确适应度评估）

```
输入: 支撑集 S ⊆ {1,...,n}
输出: (x*, f(x*), is_feasible)

求解:
  min  c_S^T x_S
  s.t. A_S x_S ≤ b                  # 10个约束
       Σ_{i∈S} x_i = 1               # 单纯形约束
       x_i ≥ 0                       # 非负约束

方法: scipy.optimize.linprog (HiGHS求解器)
```

**关键**：子LP的规模永远是 $|S| \approx m+3=13$ 个变量，与 $n$ 无关。因此评估时间 $O(1)$ 独立于问题维度。

---

## 2. 算法A：改进0-1GA

### 2.1 个体表示

- **编码**: Python `set` of int，size ≈ 10-15
- **含义**: 每个 `set` 中的整数 = 被选入支撑集的变量索引
- **优势**: 交叉/变异均为 $O(|S|)$，与 $n$ 无关

### 2.2 混合初始化 `initialize()`

四路混合，各占总种群 1/4：

| 策略 | 方法 | 目的 |
|------|------|------|
| **贪心** | 取 $c$ 最小的 $3K$ 个变量，随机选 $K$ 个 | 高质量初始点 |
| **恰好K** | 从 $n$ 个变量中无重复随机采样 $K$ 个 | 覆盖基础区域 |
| **欠稀疏** | 随机采样 $K/2$ 个 | 探索极稀疏支撑集 |
| **过稀疏** | 随机采样 $3K$ 个 | 探索宽松支撑集 |

### 2.3 锦标赛选择 `_select(k=3)`

```
从种群中随机选3个个体
可行性优先: 可行解 > 不可行解
同级比较: 目标值小的胜出
```

### 2.4 稀疏保持交叉 `_crossover()`

```
取两个父代支撑集的并集 U = S₁ ∪ S₂
目标大小: k = (|S₁| + |S₂|) / 2
从 U 中随机选 k 个元素 → 子代
```

**特点**: 自动保留两个父代共同的优良支撑模式，同时引入新组合。

### 2.5 自适应多策略变异 `_mutate()`

| 概率 | 策略 | 方法 | 目的 |
|:---:|------|------|------|
| 50% | **随机替换** | 删 1-2 个 + 采样添加 1-2 个 | 纯随机探索 |
| 30% | **贪心添加** | 采样 500 个候选，选 $c$ 最小的 3 个之一加入 | 利用目标函数信息 |
| 20% | **贪心删除** | 删除当前支撑集中 $c$ 最大的 1 个 | 稀疏化 |

### 2.6 1-opt 局部搜索 `_ls()`

```
Phase 1 (添加): 采样 150 个未选变量，优先低c，逐一测试加入
                → 首个改进接受 (First Improvement)
Phase 2 (删除): 按c降序测试删除当前支撑集中元素
                → 首个改进接受
```

每 15 代执行一次，对精英个体进行。

### 2.7 LRU 缓存

支撑集 → LP结果的映射缓存：
- 容量上限: 3000-5000 条目
- 淘汰策略: 删除前 200 个最早条目（近似LRU）
- 命中率: ~10%，减少重复评估

### 2.8 自适应参数

| 参数 | 自适应规则 |
|------|-----------|
| 变异率 | 固定（变异量由 `poisson` 分布控制期望 1-2 位翻转） |
| 稀疏偏好 | 贪心添加/删除自动倾向稀疏 |
| 收敛检测 | 连续 40 代无改进 → 停止 |

## 3. 算法B：标准0-1GA（对照）

与改进0-1GA使用**相同的 LP Oracle**，但**去除所有改进**：

| 组件 | 改进0-1GA | 标准0-1GA |
|------|----------|----------|
| 初始化 | 贪心+多稀疏度 | 纯随机 K 个 |
| 交叉 | 并集→随机子集 | 均匀交叉（每位独立选父代） |
| 变异 | 自适应+贪心导向 | 固定 `poisson(2)` 位翻转 |
| 局部搜索 | 1-opt add/drop | 无 |
| 缓存 | LRU 3000-5000 | 无 |
| 参数 | 自适应 | 全固定 |

**目的**: 量化各改进措施的贡献。

## 4. 算法C：标准连续GA（对照）

### 4.1 编码与修复

```
编码: x ∈ Rⁿ (实数向量)
修复: clip(x, 0, ∞) → x / Σx  (投影到单纯形)
```

### 4.2 适应度

$$f(x) = c^T x + 10^4 \cdot \sum \max(0, A_i x - b_i)^2$$

约束违反用二次惩罚项，权重固定 $10^4$。

### 4.3 算子

| 组件 | 方法 | 参数 |
|------|------|------|
| **交叉** | SBX (Simulated Binary Crossover) | $\eta_c = 20$ |
| **变异** | 多项式变异 (Polynomial Mutation) | $\eta_m = 20$, 概率 $1/n$ |
| **选择** | 锦标赛 (k=3) | 可行性优先 |

## 5. 高效采样 `fast_sample()`（大规模专用）

### 5.1 问题

`np.random.choice(n, k, replace=False)` 在 $n=1,000,000$ 时内部分配 100 万元素的 int32 数组（4MB），每代数十次调用 → 内存爆炸。

### 5.2 解决方案：拒绝采样

```python
def fast_sample(rng, n, k, exclude=None):
    result = set()
    while len(result) < k:
        vals = rng.randint(0, n, size=(k - len(result)) * 3)
        for v in vals:
            if v not in result and (exclude is None or v not in exclude):
                result.add(v)
    return array from result[:k]
```

- 碰撞概率: $|S|/n \approx 13/10^6 = 0.0013\%$
- 内存: $O(k)$ 而非 $O(n)$
- 期望迭代: $1.000013$ 轮

## 6. Gurobi 精确求解

### 6.1 连续LP

```python
x = model.addMVar(n, lb=0.0, ub=1.0)      # 连续变量
model.addConstr(x.sum() == 1)
model.addMConstr(A, x, '<', b)
model.setObjective(c @ x, GRB.MINIMIZE)
model.setParam('Method', 0)                # Primal Simplex
```

### 6.2 0-1 IP

```python
x = model.addMVar(n, vtype=GRB.BINARY)     # 0-1变量
# 其余同上
```

### 6.3 为什么 Gurobi 极快

对偶问题只有 $m+1=11$ 个变量，Dual Simplex 在 11 维空间中只需数次迭代。

## 8. 复杂度分析

| 操作 | 改进0-1GA | 标准0-1GA | 标准连续GA |
|------|:---:|:---:|:---:|
| 初始化 | $O(K \cdot \text{pop})$ | $O(K \cdot \text{pop})$ | $O(n \cdot \text{pop})$ |
| 交叉 | $O(K)$ | $O(K)$ | $O(n)$ |
| 变异 | $O(K)$ | $O(K)$ | $O(n)$ |
| 适应度 | $O(K^3)$ (LP) | $O(K^3)$ (LP) | $O(n)$ |
| 局部搜索 | $O(K \cdot \text{LP})$ | — | — |
| **代内总计** | $O(\text{pop} \cdot K^3)$ | $O(\text{pop} \cdot K^3)$ | **$O(\text{pop} \cdot n)$** |

$K \approx 13 = \text{常数}$，因此改进/标准0-1GA 的复杂度**与 $n$ 无关**。
