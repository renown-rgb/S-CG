# 改进遗传算法求解稀疏单纯形LP — 项目框架

## 一、问题定义

```
min  c^T x
s.t. Ax ≤ b,   Σx_i = 1,   x_i ≥ 0,   x 稀疏
```

- n : 变量维度 (100 ~ 1,000,000)
- m : 线性约束数 (固定 10)
- 稀疏: 最优解至多 m+1=11 个非零分量 (LP顶点定理)

## 四、主文件结构 (final_benchmark.py)

```
1. generate_problem(n, m, seed)     → 随机生成稀疏LP实例
2. fast_sample(rng, n, k, exclude)  → 高效无重复采样 O(k)
3. Improved01GA                     → 改进0-1遗传算法
   ├── initialize()         混合初始化 (贪心+K/欠稀疏/过稀疏)
   ├── _lp(support)         约化LP精确求值 + LRU缓存
   ├── _crossover(s1,s2)    集合并→随机子集
   ├── _mutate(s)           自适应: 替换/贪心添加/贪心删除
   ├── _ls(s)               1-opt局部搜索 (add + drop)
   └── run()                主循环 (精英+选择+交叉+变异+LS)
4. Standard01GA                    → 标准0-1遗传算法 (无改进)
   ├── 纯随机初始化
   ├── 均匀交叉 + 固定位翻转
   └── 无缓存/无LS/无自适应
5. StandardContinuousGA            → 标准连续实数GA
   ├── SBX交叉 + 多项式变异
   └── 惩罚函数 + 事后修复 (clip+归一化)
6. gurobi_solve(prob)              → Gurobi精确LP求解
7. run_benchmark()                 → 五维度实验主流程
```

## 五、0-1分解的核心逻辑

```
连续LP:  min c^Tx  s.t. Ax≤b, Σx=1, x≥0
           ↓ LP顶点定理: 最优解至多 m+1 个非零分量
         
0-1重构:  min_{z∈{0,1}ⁿ}  g(z)
         g(z) = 在 supp(z) 上求解约化LP

外层 ─── GA搜索 {0,1}ⁿ 支撑集组合空间
内层 ─── LP精确求值 (HiGHS, 子问题仅10-15个变量)
```
